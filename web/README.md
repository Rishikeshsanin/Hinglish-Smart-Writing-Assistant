# IndicWrite Online Edition (Vercel Hobby)
This is a **separate** public web edition using AI4Bharat's **official hosted IndicXlit API**, not the locally verified Python/Fairseq checkpoint. Source is in this repo, deploy root directory `web`, framework Other, no paid services or credentials.
The free hosted provider may change or become unavailable. No fallback text is invented; the UI displays an error. Entered Roman words travel to the external AI4Bharat service and should not contain sensitive content. The project's private BharatGen checkpoint and human review remain excluded from the public deployment.
**Never claim the 40-case Python checkpoint results measure this provider's live API.**
